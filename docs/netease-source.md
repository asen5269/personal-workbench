# 网易云音源后端

当前音乐源为网易云。采用社区维护的 `@neteasecloudmusicapienhanced/api@4.41.1`，作为模块加载到现有 Fastify 后端，不额外启动一个 API 服务。原 Audius 后端、前端组件和自动测试已移除。

播放器已扩展为分类发现、个人曲库、云端歌单、音质选择、歌词评论、MV 与播客，并提供全部 449 个模块的接口目录。详细范围与实测边界见 [功能覆盖说明](music-player-coverage.md)。

## 使用

`npm install` 后运行 `npm start`，打开 `/music`。默认「在线音乐」展示网易云新歌，可搜索歌曲/艺人、翻页、播放、收藏和加入歌单。本地音乐功能保留。

默认游客访问。在「在线音乐」右上角点击「扫码登录」，使用网易云音乐 App 扫码并在手机上确认。可取消、刷新过期二维码及退出本工作台中的登录。退出不会注销手机 App 的账号。

扫码成功后的 Cookie 只保存在本机后端内存，不返回前端、不放进播放地址、不写进音乐数据库；服务重启后需重新扫码。也可在启动环境中设置 `NETEASE_COOKIE`。界面退出后立即停止使用该凭据，不会自动回退到环境变量中的旧 Cookie。

登录状态接口会核实账号，网络故障不会直接删除已有凭据；关闭弹窗、切换页面或取消后停止轮询。轮询约每 3 秒一次，服务端限频、会话限时、校验本机来源，并在账号变化时清除歌曲权限缓存。登录和退出会停止旧的在线播放会话，下一次播放重新验证权限。

登录接口：`POST /api/music/netease/auth/qr`、`POST /api/music/netease/auth/check`、`DELETE /api/music/netease/auth/qr/:id`、`GET /api/music/netease/auth/status`、`POST /api/music/netease/auth/logout`。二维码状态：800 过期、801 等待扫码、802 等待确认、803 成功。登录确认只返回状态与昵称，绝不返回 Cookie。

会员、付费与地区版权仍按网易云实际返回结果执行。无可用地址会明确提示；官方仅提供试听时，返回 `preview: true` 并在当前歌曲中显示「试听」，不把试听当成完整播放。风控或限流时提示稍后重试，不通过更换身份、伪造地区或解锁服务绕过。

## 接口

- `GET /api/music/netease/tracks?q=关键词&offset=0`：每页 20 首。空关键词调用 `top_song` 并切片；关键词调用 `cloudsearch`。只接受关键词与分页，忽略代理等额外参数。
- `GET /api/music/netease/tracks/:id`：查询详情及当前账号可用播放地址，返回曲目元数据和试听标记，不返回 Cookie 或签名音频地址。
- `GET /api/music/netease/stream/:id`：重新校验或复用 30 秒有效缓存，302 跳转官方 CDN。音频 Range 请求由网易云 CDN 处理。
- 原 `/api/music/audius/*` 返回 404。

播放默认标准音质，可选择极高、无损和 Hi-Res（仍受账号和解码能力限制）。当前 SDK 默认的 xeapi 需要额外公钥，实测缺失；采用 SDK 自带的 `crypto: eapi` 请求 `song_url_v1`，未修改 SDK 源码。所有请求显式禁止随机地区 IP 和 unblock，业务调用采用明确入口，不任意透传 SDK 模块。

服务端只接受数字歌曲 ID，并对返回地址做协议、凭据、端口与网易云 CDN 域名白名单校验。不会代理用户提交的任意 URL，也不缓存整首音频。

## 数据与移除旧源

歌曲与歌单仍保存在当前浏览器 IndexedDB。已保存的旧源记录不再载入页面、播放队列或歌单，旧源当前曲目会被清空；不删除旧记录，不把旧平台 ID 错当成网易云 ID，也不改变本地音乐文件。

## 验证与依赖

`node --test tests/netease-auth.test.js tests/netease.test.js tests/music.test.js` 覆盖扫码状态、取消/过期、并发退出、跨站拦截、凭据隔离、权限缓存刷新、搜索/分页、CDN 白名单、试听和单例播放。真实账号授权需用户本人扫码确认。

联网验证：匿名搜索、新歌列表及免费歌曲的官方标准音质地址已实测成功。上游也曾返回网络风控，已明确呈现为暂时性失败；不承诺所有歌曲或每次请求均可播放。

新 SDK 引入的 `basic-ftp` 依赖存在已知高危告警，已通过限定在 `get-uri` 下的依赖覆盖固定到 6.2.6；安装审计恢复为原有两项中危告警。当前后端不开放 PAC/FTP 代理参数。
