# 书架重构

方向：私人藏书室。纸页、墨色，主题色只用于操作与阅读标记；保留原有 IndexedDB。

1. 间距：工具栏合并，统一 16/24/32/40px 分组节奏。
2. 色彩：中性封面、低饱和表面，阅读背景独立切换。
3. 图标：沿用 Tabler，移除封面重复图标。
4. 文案：仅保留搜索、排序、导入及实际状态，不恢复标题、口号和说明。
5. 字体：界面沿用项目字体；封面采用衬线书名；正文保留三类字体与字号设置。
6. 布局：书架紧凑工具栏；阅读器目录、正文、设置三栏，窄屏堆叠。
7. 细节：封面书脊、真实字数、真实阅读位置，按章节和段落分页，修复同页章节误选。
8. 视觉：内容本身承担视觉重点，不使用生成装饰图或虚构藏书。
9. 动效：统一 transform/opacity、按压反馈、可见焦点、减少动态效果支持。

验证：浏览器导入测试 TXT，打开阅读、翻到第二章、展开设置、切换夜间、返回查看 59% 阅读位置均正常。测试书籍已移除。截图 artifacts/bookshelf-reader.png。构建通过。
