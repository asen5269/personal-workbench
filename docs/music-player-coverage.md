# 音乐播放器功能与接口覆盖

本次范围按用户确认执行：**播放器完整功能＋全部接口目录**。不是把仓库所有业务模块全部开放为可执行接口。

## 接口目录

- 安装版本：`@neteasecloudmusicapienhanced/api@4.41.1`。
- 当前安装包 `module/` 内有 449 个 JS 模块，目录逐一对应，没有手动省略条目。
- 39 个模块已连接播放器业务入口；其余分别标为「仅目录，未接入」或「底层或特殊接口，未开放」。这项标记表示代码连接关系，不代表每个接口都已通过真实账号验收。
- 界面入口：「在线音乐 → 接口目录」。支持搜索、分类、状态筛选、分页、参数提示及仓库源码链接。
- `GET /api/music/netease/catalog` 返回完整目录。没有提供可任意执行模块、透传 Cookie、代理地址或底层请求的通用调用器。
- 目录生成工具：`python artifacts/build-netease-catalog.py`。升级 SDK 后应重新生成，并通过目录与安装包一致性测试。

## 已实现的播放器功能

| 模块 | 行为 |
|---|---|
| 本地曲库 | 文件/文件夹导入、标签与封面、收藏、本地歌单、搜索排序、重定位 |
| 单例引擎 | 跨页面播放、上下首、进度、音量静音、四种模式、播放列表、恢复进度 |
| 网易云登录 | 扫码、等待确认、过期刷新、取消、退出、凭据仅后端内存 |
| 在线发现 | 歌曲搜索、新歌速递、精选歌单、歌单搜索、榜单、歌手搜索、专辑搜索 |
| 合集详情 | 歌单、榜单、专辑、歌手热门歌曲、电台节目；歌曲分页及播放本页 |
| 个人内容 | 每日推荐、私人 FM、自己的云端歌单、云端喜欢、音乐云盘、最近播放 |
| 云端歌单 | 新建私密歌单、重命名、删除、加入/移除单曲、收藏/取消收藏歌单 |
| 云端喜欢 | 红心单曲、取消喜欢，区别于工作台本地喜欢 |
| 歌词 | 原文、译文、时间同步高亮、点击歌词跳转；从页面与底部栏打开 |
| 评论 | 评论分页、点赞/取消点赞、确认后发布评论 |
| 音质 | 标准、极高、无损、Hi-Res；按账号权限实际返回，切换保留播放位置 |
| MV | 列表、官方播放地址、视频播放；播放 MV 时暂停音乐 |
| 播客 | 热门电台、节目列表，复用歌曲播放引擎；可用性以官方返回为准 |

新建云端歌单默认私密。删除、移除歌曲、评论发布等操作先展示具体确认内容。后台再校验登录与歌单所有权，防止修改他人歌单；账号写操作不进入读取缓存。

## 验证结果

- 构建通过；原有音乐、扫码登录与网易云后端测试继续覆盖。
- 新测试覆盖：449 项目录一致性、公开浏览/合集、个人内容登录要求、写入确认和所有权、歌词解析及当前行定位、音质参数验证。
- 本机匿名联网实测：歌单、榜单、专辑、歌手列表均 HTTP 200；歌单/专辑/歌手/电台详情可返回歌曲；歌词和评论可读取。
- 每日推荐等私人接口在未登录时明确返回 401，不使用假数据或其他账号替代。
- 云端写入的验证使用模拟接口，没有替用户发布评论、创建/删除云端歌单或修改红心收藏。真实账号功能需用户扫码后验收。
- 上游可能有版权、会员、网络风控与浏览器编码限制。音质选项不承诺自动获得对应权限；试听明确标记。

## 未集成到播放器 UI 的业务

私信、动态社交、账号注册/换绑、创作者后台、VIP 任务、云贝任务、付费购买、上传发布及底层加解密等仍保留在全部接口目录中，未伪装成已实现功能。没有批量调用这些接口。

本次没有新增系统托盘、开机自启、蓝牙自动化、音频均衡器、整曲离线缓存或在线歌曲下载。当前登录仅保存在后端内存，服务重启后需要重新扫码。云端数据与 IndexedDB 中的工作台数据独立，不进行未经用户操作的双向同步。
